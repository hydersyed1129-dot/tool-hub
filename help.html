How do I use a tool?

Choose a tool from the home page, enter the requested values or select a file, and use its action button. Tool Hub works in current desktop and mobile browsers.

Where are my files processed?

Image and PDF operations run in your browser. They are not uploaded to a Tool Hub server. For more information, see the Privacy Policy.

Why are QR or PDF features unavailable?

Those tools load a supporting library from the internet. Check your connection, then reload the page.

Something is not working

Try reloading the page and checking your input. If the problem continues, report it to us.
